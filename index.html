  • Right-click: Add new point
  • Left-click: Toggle valid/invalid (red/gray)
  • Double-click: Select/highlight (blue)
  • Drag: Move point
  • Mouse wheel: Resize point
  • Ctrl + Wheel: Zoom in/out
  • Ctrl + Click/Drag: Pan when zoomed
  • Ctrl + R: Reset zoom
